## 技術判定

**attempt1 の欠陥 = 「監査が見つけた欠陥は直したが、コーパス既定の用語から外れた」**

- `q007`: JP「体力」を漢字のまま zh「体力」と訳した (中文では肉体的な力の意)。
  コーパス実測 `expl_tr_*.json` **2786 件中 0 件**、現行 disk 版は「实力」= **現行より後退**。
- `q049`: 「结合测试（集成测试）」と主従を逆転。先例 `expl_tr_2011h23a-q044.json` は
  「集成测试（结合测试）」で、目標言語側は標準用語を主表記に置くのがコーパス既定。
- `q061`: 「稼働時間」を `运转时间` と訳した。コーパス実測 `正常运行时间` 10 件 / `运转时间` **0 件**。

**R1 で捕まった主 context 自身のバグ**: q049 で「结合测试（集成测试）→集成测试（结合测试）」の
主従逆転置換の**後に**「结合测试→集成测试」の裸語置換を走らせたため括弧内まで潰れ、
**「集成测试（集成测试）」という同語反復**になった。核験は「置換の適用順序ミスの産物」と特定した。
→ **教訓: 括弧内をガードするか、置換順序を「裸語 → 主従逆転」に逆転させる。**
