### ① キタミ式イラストIT塾 ITパスポート 令和08年（技術評論社，A5，ISBN 978-4-297-15299-4）
- 书页：https://gihyo.jp/book/2025/978-4-297-15299-4
- 样张（PNG，1000px 宽见开き）：
  - https://gihyo.jp/assets/files/book/2025/978-4-297-15299-4/9784297152994-01.png ～ `-05.png`（01 到 05 共 5 张）
  - 旧版 R07 也有 5 张：https://gihyo.jp/assets/files/book/2024/978-4-297-14478-4/9784297144784-01.png ～ `-05.png`
- 紙面：**很标准的 2 色印刷（墨 + 赤茶／テラコッタ橙）**，和本项目“navy + 一个橙色”的方向最接近。
  - 页面底色是淡米色加横线，像笔记本纸，页顶还画了活页环。
  - 章扉：横贯见开き的橙色粗带，里面放一个白色圆章「Chapter 7」，大号白色粗体标题**反白**排在色带上。下面接 16 格编号漫画（4 格×4 段，每格右下角有黑色圆形编号），用角色对话把概念引出来。
  - 节标题：橙色色带两端画了“胶带”，白字反白，例如「LANの接続形態（トポロジー）」。小标题用「パケット交換方式」这种黑框标签，放在淡橙底的图解面板里。
  - 重要语是**橙色文字（不加粗）**。表格左列铺淡色底。要点总结放在一个淡色圆角框里，配橡子角色。
  - 柱 / ノンブル：外侧书口有圆形章号加竖排章名的 tab。ノンブル是底部居中的橙色药丸形。
  - 没有找到「赤シート対応」的说法（重要语是橙色，**未验证**能否用红膜遮住）。

### ② かやのき先生のITパスポート教室 令和08年（技術評論社，ISBN 978-4-297-15243-7）
- 书页：https://gihyo.jp/book/2025/978-4-297-15243-7
- 样张：https://gihyo.jp/assets/files/book/2025/978-4-297-15243-7/9784297152437-01.jpg / `-02.jpg` / `-03.jpg`
- 紙面：**多色粉彩**（紫、粉、红、蓝），不属于 2 色系，但组件很值得借鉴。
  - 每个主题开头：紫色大号「1 05」编号，下面是「イメージでつかむ」插画框。
  - **出題頻度标签**：「時々出｜必須｜超重要」三个小标签排成一排，命中的那一个反白（灰底白字）。
  - 小节标题是粉色药丸形，白字反白。重要语用**红/粉色粗体**，定义句用黑色粗体。出版社写明「重要用語を隠せる赤シート付き」。
  - 招牌框是「“くれば”で覚える」，写法如「デュアルシステム とくれば 二組のシステムで、同じ処理をして照合する」，即“术语→一句话答案”的记忆卡。另有蓝色圆角的「もっと詳しく」补充框。
  - 確認問題页铺淡蓝底：
    - 每题一条反白标签，写「確認問題 1」，后接出处（如「平成28年度秋期 問65」）和「正解率 高/中」，右端是黑色圆形「基本/応用」徽章。
    - 解说用戴博士帽的吉祥物「要点解説」引出。
    - 见开き底部有一条「解答」栏：「問題1:エ 問題2:エ …」。
  - 柱是右上角的药丸「1-05 入出力装置」。书口是竖排反白章 tab。

### ③ ITパスポート パーフェクトラーニング過去問題集 令和08年【上期】（技術評論社，ISBN 978-4-297-15230-7）

## 3. 综合：各书共通、Web 可以借用的惯例
1. **反白编号标签**：「問 42」「確認問題 1」「解説」「解答」在至少 4 本书里都用“色底白字方块”。这和店主“navy 反白「問1」「解説」”的想法完全一致，可以直接用。
2. **ア/イ/ウ/エ 做成小反白方块**（パーフェクトラーニング、かんたん合格），解说里也用同一个字形指代选项（「正解は［ウ］」）。
3. **逐项判定**：解说里按「× ア … / ○ ウ 正解です」一行一项（かんたん合格）。Web 上可以把用户选错的那一项高亮。
4. **页末“解答”汇总栏**：一个见开き或一组题结束时，放一条「解答 問42 ア 問43 ア…」（3 本书都有）。Web 可以做成“本组答案条”，默认遮住、点击展开。
5. **✓✓✓ 三格复习勾选**（パーフェクトラーニング、かんたん合格）对应间隔复习的次数，适合映射到用户的做题历史。
6. **出題頻度 / 重要度标记**有两种写法：
   - 星级「頻出度 ★★☆」（徹底攻略）；
   - 文字徽章「高／中」「時々出｜必須｜超重要」（パーフェクトラーニング、かやのき）。
   - 加上「正解率 高/中」和「基本/応用」（かやのき）。
7. **出处行**：每题标「令和4年度 問87」「H31春 問54」。
8. **要点框体系**：「ココが出る!」「これも知っとこ」「ココを押さえよう」「合格のカギ」「“くれば”で覚える」，几乎每本都有 1～3 种命名固定的框，经常配吉祥物。
9. **书口分野 tab + 柱**：按ストラテジ / マネジメント / テクノロジ分层，当前项反白。Web 上可以对应成侧边 rail 或面包屑。
10. **重要语强调**：用 spot color 文字或粗体（可以遮住），再加波浪线或点线下划线。“赤シート”的逻辑由かやのき、TAC 明确提供。
    - **注意**：我看过的所有内页里，**都没有黄色荧光笔底**这种做法。荧光笔只出现在インプレス的宣传图上。内页一律用彩色字和下划线。黄色荧光笔算是本项目自己的选择，不是这些书的惯例。

## 4. 两种问题版式（Quiz 视图最关键的选择）
- **A：左题右解，见开き完结**（かんたん合格 過去問題集；据称 TAC 也是）：每个见开き 3 题，解说正对题目。适合桌面宽屏：左栏放题，右栏放解说，作答后右栏才显示。
- **B：题目集中在左，解说两栏流排**（パーフェクトラーニング）：左页连放多题，右页按题号连续解说。适合“先连做一组再对答案”的模式。

## 5. 几种有特色的处理
1. キタミ式：用**编号格漫画做章扉**，整本都是墨 + 赤茶 2 色，配笔记本横线纸的底纹。它证明“2 色 + 手绘”就能撑起 600 页，和本项目配色最接近。
2. かやのき：「〇〇とくれば××」一行式记忆卡，加上三档频度标签，加上赤シート，可以直接做成用语表的卡片组件。
3. パーフェクトラーニング：卷头「単語集 厳選30」带排名和「UP↗」上升徽章，适合 glossary 的“出題ランキング”视图。
