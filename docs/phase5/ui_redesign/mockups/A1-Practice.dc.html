A社がB社に作業の一部を請負契約で委託している。作業形態 a〜c のうち、いわゆる偽装請負とみなされる状態だけを全て挙げたものはどれか。

aB社の従業員が、A社内において、A社の責任者の指揮命令の下で、請負契約で取り決めた作業を行っている。
bB社の従業員が、A社内において、B社の責任者の指揮命令の下で、請負契約で取り決めた作業を行っている。
cB社の従業員が、B社内において、A社の責任者の指揮命令の下で、請負契約で取り決めた作業を行っている。
ア× a 你的答案
イ a，b
ウ a，c 正解
エ b，c
答错的题已放进错题本，3 天后再出。

解说

判断看“谁在指挥命令”，与在哪里干活无关。承揽合同中应由 B 公司指挥自己的员工；a、c 都由 A 公司负责人指挥，实质是劳动者派遣，属于伪装承揽。所以答案是 ウ。

ア 只列出了 a。c 虽在 B 公司内作业，仍受 A 公司指挥，同样是伪装承揽。
