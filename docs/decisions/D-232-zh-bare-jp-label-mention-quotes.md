# D-232 — zh: 裸の `[[jp:]]` は「言及」なら引号で囲み、漢字間の空白を置かない (C25b)

- 状態: **LOCKED** (2026-11-16 Session 160、委任判断 D-161、Fable 諮問を採用)。**規則 1 の引号の形 (「欄に「があれば「」」) は D-233 (S161) で置き換え: 常に “”**
- 関連: D-231 (太字キーワードの縁の空白、本 D はその §維持 4 の続き)、D-215 C2 (`compatText`)、C17 (S154、glossary 可視欄の裸ラベル判定。本 D がその KEEP の一部を改める)

## 対象
zh の content 欄の **裸の `[[jp:X]]`** (直前が `**キーワード**` でないもの。キーワード直後のラベルは `compatText` が括弧を付ける)。
- 読書画面では `[[jp:]]` は色付き `<span lang="ja">` で区別される。
- 派生の平文欄 (terms[].definition / explanation / memory_hook ← one / detail / hook) は glossary・TodayTerms に色なしで出る。漢字のラベルが漢字に接すると中国語の文に溶ける (「日语与信字面就是」)。

## 規則 (字種ではなく働きで分ける)
1. **言及** (日本語の語そのものを話題にする: 「日语的X相当于」「X就是英语…」「也称作X。」「X对应 Public」) で、glossary 可視欄にあり、ラベルの漢字の端が漢字に接する (または空白で隔たる) もの → **引号で囲み、隣の空白を消す**。
   - 引号は欄に既に「 があれば「」、なければ “”。同じ文の中で引号の形を混ぜないため (例「日语「負債」中的「債」」)。
   - 並列の言及は対で揃える (technology-22-60-u05「“放送局”（广播电台）、“郵便局”（邮局）」、technology-22-60-u04「“光ファイバ”里的“ファイバ”」)。
2. **注釈** (訳語の後の原語「响应时间[[jp:レスポンスタイム]]」、括弧内の「也叫X」) と **仮名の端の言及** (「日语读作エルシー」は字種で区切れる) と **読書画面だけの欄** (points・key_points) → **漢字間の空白を消すだけ** (D-231 と同じ)。
3. 括弧内の注釈で空白が唯一の区切りのもの 1 件 (technology-16-44-u04 `terms[2].one_zh`「总拥有成本 [[jp:総所有コスト]]）」) → 空白を「，」に (多数形「（信息物理系统，[[jp:…]]）」)。
4. **維持**: 既に区切られた注釈 (「又称[[jp:決定木]]）」) 6 件。`compatText` は変えない。

## 結果 (S160)
- 候補 102 (空白 97 = 73 ラベル + glossary 欄の漢字接触の言及 29)。Q 52 / D 43 / C 1 / K 6。
- 81 欄・44 単元。派生追従 110 欄 (memory_hook 48・memory_hooks 48・explanation 9・definition 4・key_points 1)。
- 再走査: 対象 0、裸ラベルの隣の CJK 間空白 0。

## 根拠
- 平文欄で区切りが消えるのは S159 の C25b 保留理由そのもの (D-231 §維持 4)。空白は中国語の区切りとして働かない (「日语 与信 字面」も曖昧)。
- コーパス: zh content 欄の `“[[jp:]]”` 116 / `「[[jp:]]」` 42 (Fable 計数)。既に「里的“[[jp:局]]”」の形で言及を引号で示している。
- 中国語で特に指し示す語に引号を使う慣行 (GB/T 15834-2011 の引号の用法。**条款番号は未照合**)。

## 却下
| 案 | 理由 |
|---|---|
| 言及の空白を残す (D-231 の例外) | 空白は中国語の区切りではなく平文でも曖昧。多数の粘着形と逆 |
| `compatText` で漢字の裸ラベルに自動で括弧 / 引号 | 言及と注釈を token で区別できない (「日语的[[jp:憲章]]相当于」と「装置[[jp:無停電電源装置]]填补」が同形)。既存の引号と重なる |
| 空白付きの 73 だけ直す | C17 の粘着した言及 (「日语的憲章相当于」) と同じ曖昧さが残り、偶然の空白で線を引くことになる (Fable) |
| 一律 “” | 「」を既に使う欄で混在する。「」の全体統一は別件 (純資産の句は「」が非ラベルの訳も包む) |
