# D-216 — 確認題は単元で解ける題に限り、無ければ 3 未満を認める (OQ-20 の処置)

- 状態: **LOCKED** (2026-11-11 Session 153、ユーザー「我觉得可以按照你的建议来」→ Claude 推奨案)
- 部分 supersede: D-196 §0-1 の確認題数 3〜5 (min 3) — 例外登録した単元に限り min を外す。max 5 は不変。
- 関連: D-215 (Phase 3c 掃除 pass) C11、OQ-20 (本決定で CLOSE、実施は S154〜)

## 背景
S153 C11 調査 (`evidence/phase5/stage_07_ui/phase3/cleanup/C11.md`): challenge_questions 1073 件のうち、考点に紐付かず見出し語も含まない 114 件を opus 2 体が判定 → REMOVE 96 件 (40 単元)。外すと D-196 §0-1 の min 3 を 33 単元が割り、9 単元は 0 件。v1 から継承した無関係題が単元末の確認題として出ており、その単元を読み終えた学習者には解けない。

## 決定
1. **差し替え優先**: REMOVE 対象の各単元について、同 topic の過去問 (中問組員・既使用を除く) から「その単元の本文で解ける」題を判定して差し替える。判定は opus、審査は別 subagent_type (Rule D)。
2. **無ければ少なくてよい**: 差し替え後も 3 に届かない単元は 0〜2 題を認める。ただし例外は **登録制**: fixture (例 `confirm-short.json`: unit_id → {n, reason, evidence}) に載った単元だけ validateV2 が min を外し、件数が登録値と一致することを検査する (PRE_D202 と同じ較正型)。未登録の単元は従来どおり min 3。
3. **表示**: 確認題 0 件の単元は確認題節を出さない (空見出しにしない)。1〜2 件はそのまま出す。
4. **D-196 の他の部分は不変** (max 5、中問組員の除外、用語の quiz からの補充順)。

## 却下
- 差し替えのみ (案 1): 9 単元は同 topic に解ける題が無い見込みで、min 3 を満たすには無関係題を残すしかない。
- min の一律撤廃 (案 2 単独): 解ける題がある単元まで減らしてしまう; 例外の理由が残らない。
- 現状維持 (案 4): 解けない題が確認題として出続ける (学習者に見える誤り)。
