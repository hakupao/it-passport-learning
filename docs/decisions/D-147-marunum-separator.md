# D-147 — 丸数字列挙 (①②③) の区切り字種: 出荷層は ASCII「, 」に統一、脱落は保真差分、字種差は表記揺れ

- **Status**: Locked (Session 123, 2026-09-08)
- **ユーザー gate**: S122 §6 / PLAN §0 が「U3b (`2019h31h-q062`) 前に全体方針を固定」を要求。S123 で D-019 の開放質問 4 件を提示 → ユーザー「你来定 (権威依拠を調べて lock)」。
- **Relates**: D-140 (OCR-garble scale 方針)、D-143 (final note)、D-146 (分批)、⑨ cosmetic 横断 (ASCII 引用符 139 問 / 読点字種)。

## 背景 — 事実 (S123 実測、questions.json 2900 問 + translations sidecar)
- 選択肢が丸数字の組合せ (「①, ②」型) の問は **23 問**。区切り字種は 4 種併存: ASCII「, 」/「,」 10 問、全角「，」(U+FF0C) 10 問、中文「、」1 問 (2014h26h-q076)、**区切り無し** 2 問 (2015h27h-q070 / 2019h31h-q062)。
- 源 (IPA PDF) は横書きで読点に「，」を用い、丸数字の間も「①，②」(2019h31h-q062 の crop で目視)。ただし S122 reviewer の判定どおり、**源の字形から「，」と ASCII「,」を画素で判別することはできない** (等幅フォント + 空白)。
- 出荷層 (stem_jp_clean / choices_jp) の読点はデータセット全体で既に混在: stem 2900 問中 ASCII「, 」1831 / 「，」594 / 「、」235 (choices も同比率)。**どの exam も同じ混合比 (ASCII ≈ 65% / 「，」≈ 20%)** で、「exam 単位の慣例」は存在しない。丸数字問 23 問の題幹読点も問ごとにばらばら。
- 波 2/3・S122 の house rule は ASCII「, 」(2018h30h-q072 / q085 等 10 問はこれで Rule D PASS 済)。
- 権威: 文化庁「公用文作成の考え方 (建議)」(令和 4 年 1 月 7 日) Ⅰ-5 (1) ア: 「句点には『。』読点には『、』を用いる。横書きでは、読点に『，』を用いてもよい。**ただし、両者が混在しないよう留意する**」。同 イ: 中黒「・」は並列する語の区切り。→ 規範が要求する核心は**一文書内の統一**であり、字種そのものは横書きで選択可。

## 決定
1. **jp 出荷層 (choices_jp / choices_jp_clean / .phase1 / bank 三層)** の丸数字列挙区切りは **ASCII コンマ + 半角空白「①, ②」に統一**する。根拠: (a) データセットの読点多数派 (≈ 65%) と同じ字種、(b) 既に Rule D PASS 済の 10 問 (house rule) を触らない、(c) 源の字種は判別不能なので「源忠実」は成立せず、統一の根拠は公用文建議の「混在させない」に置く。
2. **保真核験 (⑤-2) での扱い**: 区切りの**脱落** (「①②」) は源に区切りがある以上 **cosmetic 差分として計上・是正**する (S122 q085 と同じ)。区切り**字種**の差 (「，」↔「, 」↔「,」) は fidelity prompt の「句読点/全半角/空白の表記揺れは許容」に該当し、**差分に計上しない** (machdiff `normStr` も同一視)。fixer は本 D の字種に揃えて書く。
3. **zh 層**: 並列は中文規範の頓号「①、②」に統一 (現状「、」/「，」/「,」/無しの 4 種)。**en 層**: 「①, ②」を基準、末尾の「and」(「① and ②」) は自然英語として**適合扱い** (書換えない)。「，」「、」「無し」だけ是正。en の数字様式 (① vs (1)) の統一は本 D の対象外 (⑨)。
4. **適用**: 決定的脚本 `scripts/quiz-marunum-sep-D147.mjs` (正規表現 `[①-⑳]` 間の区切りのみ、dry-run 既定) で **23 問の choices 三層 + zh/en** を本 unit (U3b) の fixer が実行し、reviewer が Rule D で全 23 問を確認する。題幹の読点・列挙 (「①～③」等) は触らない。
5. **範囲外**: stem/choices 本文の読点字種 (「，」594 問) の全庫統一は別件 (⑨、ユーザー判断)。本 D は丸数字列挙の区切りに限る。

## 却下した代替案
| 案 | 却下理由 |
|---|---|
| 源忠実 (「，」に統一) | 源の字形は判別不能で「忠実」を検証できない。出荷層の読点多数派 (ASCII) と衝突し、問内で「，」と「, 」が混在する (例: 2019h31h-q062 の題幹は「, 」)。PASS 済 10 問の再修正も発生 |
