## 理由
- ⑤-2 の agent は表示 jp 層 (clean 優先) を源と比べたので、1208 題の jp 推測補完は**既に射程内**だった (U8 q011・U10 の 3 件はこの経路で検出)。C で同じ 1208 を再抄写しても同じ射程を二重に払う (≈ 7,400 万 token) だけで、真の空白である訳層は見えない。
- 真の空白は訳層 (2,900 題すべて未照合) で、U11 で 3 件の実例 (q070 イ / q032 イ / q066)。jp が検証済なら訳層照合は画像不要で安く、D が最も費用対効果が高い。
- A は 0 token で全庫を覆い、⑨ の他の機械走査と同じ pass で回せる。ただし raw が崩れていない誤りは拾えないので、数字だけは B で源照合する (q085 型 = 正解に効きうる型)。
