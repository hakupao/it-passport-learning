## (a) 感度校正 — 実欠陥に当ててみる

`scripts/quiz-fidfix-S11{3,4,5,7}*.mjs` 25 本から、是正前の文字列 (`from` / `FIX` の jp 配列) を字句抽出。zh / en は除外、日本語を含むもののみ、重複除去して **267 件**。これは「過去に人手 + LLM 核験で実欠陥と確定した文字列」なので ground truth として使える。

| | 件数 |
|---|---:|
| 抽出した実欠陥 before 文字列 (JP) | 267 |
| いずれかのルールが命中 | **59 (22.1%)** |
| 未命中 | 208 |

ルール別の命中数 (1 文字列が複数ルールに当たることがある):

| rule | 命中 | rule | 命中 |
|---|---:|---|---:|
| R7d | 16 | R2a | 7 |
| R3 | 15 | R8b | 5 |
| R2b | 9 | R2e / R2f / R8c | 3 各 |
| R6b / R6d / R8a | 2 各 | R1b / R1c / R6c | 1 各 |

> R7d の 16 件は割り引いて読むこと。この harness は「置換前の**断片**」を 1 選択肢とみなすので、断片が助詞で終わるのは当然であり、R7d 単独命中 13 件は harness の副作用を含む。R7d を除いた実質命中は 46 / 267 = 17.2%。

### 未命中 208 件の内訳 (`from` と `to` を機械比較して分類)

| 分類 | 件数 | 判定 |
|---|---:|---|
| 語義 / 字形置換 (空白除去後の長さがほぼ同じ) | 148 | **原理的に決定的走査では不可視** |
| 文言・構造の書き換え (前文投入・表の再構築・訳文調整) | 46 | そもそも「OCR ノイズ」ではない編集 |
| `to` を抽出できず分類不能 | 11 | — |
| 記号ノイズを含むのに未命中 | **2** | 真の取りこぼし |
| 空白のみの差で未命中 | **1** | 真の取りこぼし (`2017h29h-q034` ウ「製品が “導入期”」= 開き引用符の前の空白) |

**正直な結論**: 機械的に見える欠陥 (記号ノイズ・空白・括弧の不整合) は 208 件中 3 件しか取りこぼしていない。一方で **「轟威」(脅威) /「角罪」(犯罪) /「滞進的」(漸進的) /「革積」(蓄積) /「網黄」(網羅) /「隅離」(隔離) /「プラウザ」/「ピジョン」/「TP アドレス」型の語義・字形置換は、字種も構造も正常なので本器では絶対に捕まらない**。これは ⑤-3 (層化抽検 + LLM 核験) の射程であり、⑤-4 が代替できるものではない。両者は補完関係にある。

### 後続の実読規模 (この数字が ⑤ の閉じ方を決める)

- **実読が要るのは 36 問 / 50 field** (R8 以外)。うち選択肢は 29 問 / 43 field。1 問あたり数十秒なので **1 lane で完了できる規模**。

## 再現手順

```
node --check scripts/quiz-choice-defect-scan.mjs
node scripts/quiz-choice-defect-scan.mjs --all \
  --json data/ip/quiz/.phase2/choice_defect_S118.json \
  --md   data/ip/quiz/.phase2/choice_defect_S118.md
node scripts/quiz-choice-defect-scan.mjs --exam 2017h29h        # 単一回
node scripts/quiz-choice-defect-scan.mjs --all --rule R3,R8b    # ルール絞り込み
```

感度校正の harness は scratchpad の使い捨て (`calib-sensitivity.mjs`、fidfix script から `from`/`to` を字句抽出して `RULES` / `scanQuestion` を import)。ルールを足す / 締めるときは同じ 267 件に再度当てて捕捉率が下がっていないことを確認すること。
