### 2.3 計上定義の揺れと累計の検算

**定義は 3 つある。**

| 定義 | 内容 | 差が出る unit |
|---|---|---|
| (a) U9 定義 | agent DISCREPANT 題 (非採用を除く) + machdiff 実残差 | — (基準) |
| (b) U11 定義 | (a) + fixer の走査で見つけた**出荷層 (学習者に見える層)** の残差 | U11: a 12 → b 14 (`q025` / `q084`、引用符の字種で agent CLEAN・machdiff 構造的不可視) |

U10 evidence §2 の「計上 13」は定義 (a)。U11 evidence §2 は (b) の 14 を主値、(a) の 12 を併記。U10 で計上外にした `q078` (raw のみ) と U11 で計上に入れた `q025` / `q084` (出荷層) は「学習者に見えていたか」で線を引いており、U11 §2 はこれを根拠に挙げている。**この定義の変更は D として lock されていない** (U11 Rule D は併記を条件に承認)。

**累計の検算 — 不一致 1 件**

U3a 以降の各 unit evidence は、前 unit の比較表を引き継いで累計を書いている。その表は**波 2 = 15 題 / 9.5%、波 1〜3 = 40 題 / 8.7%** のままだが、S121 Rule D (U2) は波 2 を **16 題 / 10.1%** に訂正している (`quiz_full52_wave2_S118.md` §1 の訂正注、`quiz_full52_ruleD_U2_S121.md` 波 2 MINOR-1・総括「波 2 訂正で 41 題計上」)。U3a (S122) は S121 の後に書かれたが、旧値 15 を引き継いだ。U3b / U4 / U6 の reviewer は累計を「13+15+12+…」と再計算して「一致」としており、**再計算の入力そのものが旧値だった**。

### 4.3 machdiff の構造的盲点

`scripts/quiz-fidelity-machdiff.mjs` の `normStr` (20〜27 行) は比較前に次を正規化する: NFKC (全角/半角)、空白の**削除**、読点 `，、,` → `,`、句点 `。．` → `.`、**引用符 `“”„"「」『』〝〟'` → `"` (25 行)**、波ダッシュ族、斜線、長音・ダッシュ族、丸括弧、コロン、中黒。

- **原理的に見えないもの**: 引用符の字種 (U11 `q025` / `q084`、U11 Rule D NIT-2 の母数外 `2026r08-q057`)、読点・句点の字種、全角/半角、空白の有無と量 (行跨ぎ読点後の空白 310 件、U9 NIT-4)。
- **見えるもの** (記述の訂正に注意):
  - 読点の**脱落**は正規化後も欠落として残る。U4 §3 の「読点脱落 3 件は machdiff では原理的に検出できない」を U4 Rule D MINOR-3 が実測 (patch を外した素の比較) で訂正した。**U3a §3 / U3b §3 の同旨の記述 (区切りの脱落は原理的に検出できない) は訂正されていない。** また U3a §3 の「`q096` の読点挿入は machdiff では原理的に検出できない」も誤り — `normStr` は読点を `,` に統一するだけで、「、」の脱落・挿入は正規化後も文字数の差として残る (可視)。
  - 亀甲括弧 `〔〕` と `[]` `【】` は正規化されない。これは本 summary が `quiz-fidelity-machdiff.mjs` を読んで確認したもので (`git log -S'〔'` で該当コミット 0、S117 版 `2f43aa0` から HEAD まで `normStr` に括弧の写像は無い)、波 2 で machdiff が `[条件]` を拾った実績と整合する。したがって U3b §3 の「亀甲括弧は machdiff では原理的に検出できない」は、S123 当時のコードに照らしても不正確 (reviewer の指摘ではなく本 summary の判断)。
  - 一 (漢数字) と ー (長音) は区別される (コード内注記 Rule D MINOR-3)。
- **「空虚な一致」**: machdiff は agent が計上した field に agent の修正を当ててから比べるため、agent の `current_text` が field 全文だと比較が自明に一致する (U3b §8a `q034`、U4 で採用 4/4、U5 で 17/21 field)。`same` の数は是正の前後で同じでも中身が違う。
- 引用符盲点を「⑨ 新規」とした U11 §11 / STATE に対し、U3a §3 / U3b §3 は既に「構造的盲点 (再掲)」として引用符の正規化を挙げている。新規なのは「agent も CLEAN にした出荷層残差が実在した」(U11 `q025` / `q084`) という実例のほう。
