## 4. D-209 の免除の適用 (観察)

最終ラウンドの jp-review a3 #1 / #2 で D-209 に関わる判定は 3 件ある。Rule A の目で見て、**3 件とも正しく適用されている**。免除された考点のうち、選択肢・判断項目の語句・組・順序をなお辿っているものは無い (MEDIUM に上げるべきものは無い)。

1. **但し書きの適用** (a3 #1 MEDIUM、`terms[4].points[0]`): 2024r06-q039 は判断項目 a〜d から当てはまるものを全て選ぶ組合せの題。考点は判断項目 c の語句 (二次担当へ / エスカレーションされた / 件数の割合) と題文の判定基準 (値が小さい方が良い) を組にしていた。審査は、なぞった語句を detail_jp に具体的に示し (D-209 (c))、「一般的な定義ではなく判断項目の語句の再現なので免除は無効」として MEDIUM にした。D-209 の無効条件どおりの判定で、a3 jp.r1 で考点を削除して解消。
2. **免除の適用 — 分類型** (a3 #1 low・#2 low、`terms[3].points[0]`): 引用 4 題のうち 3 題 (q047 / q044 / 2026r08-q046) は「どのプロセスか / 問題管理の説明はどれか」型、q040 は「適切な説明はどれか」型 (正答 = 問題管理の役割の区別)。考点は見出し語の一般的な定義 (根本原因 → 解決策 → 再発防止) を述べる。
