## 3. 採用した形 (D-208 追補)
- `choiceEchoWarnings` (scripts/lib/textbook-v2.mjs): 否定 + 誤答肢 cover ≥0.3 (6 字以上) または包含 (2 字以上。数字だけの肢は包含で見ない、英数字だけの肢は語境界つき = Rule D L2)、用語名は遮蔽しない (召回優先)。validate が unit / file と JP part で (loc part では出さない = Rule D L3) `warn  choice-echo  <field>  <qid> <肢>` を出す。exit code に影響しない。
- 実装での実測 (`final.mjs`): 陽性 8/14、境界 LOW 3/6、陰性 b14〜b17 20/142、b01〜b13 + 試点 81/495 (Rule D L2 の語境界・数字除外の後。前は 82)、発火した考点は単元あたり平均 1.46 件 (warn 行は qid ごとに 1 行なので、現行 v2 全 73 単元で 129 行 = 約 1.8 行 / 単元、Rule D 実測 [L2 の修正前])。
- 規則側: writer「書き方 11」((a) 誤答肢を打ち消すだけ / (b) 選択肢の組・判断項目の再現 / (c) 誤答肢の場面の再演 / (d) 穴埋め題の空欄の語を比較相手と組のまま言い換え、を禁止、warn が出た考点は読み直す)、JP 審査 観点 4 ((iii) の選択肢なぞり型 = **medium、low にしない**、warn の考点は 1 件ずつ判定し非該当も理由付き low で記録、題文側は観点 5 で突き合わせる)、Rule A 雛形に既知の不合格型 5 つを恒久化。
- 効果の指標 (暫定): b18 以降の Rule A の (iii) 型 MEDIUM 件数・批あたり補丁数。
