# C2 — zh/en 派生欄で keyword と JP ラベルが連結する問題 (D-215、S153)

## 現象
v2 本文 `**会计审计**[[jp:会計監査]]是…` を `stripInline` で平文化した compat 欄 (`definition_*` 等: glossary・AI 先生が読む) が「会计审计会計監査是…」と連結する。

## 規則の比較 (全 244 単元の zh / en 欄、S153 計数)
| 形 | zh | en | 判定 |
|---|---|---|---|
| 書き手が括弧を書いた `（[[jp:…]]）` | 4026 | 4328 | 問題なし |
| 括弧内の列挙 `（…，[[jp:…]]）` / `（[[jp:…]]，即…）` | 183 + 133 | 160 + 85 | 問題なし |
| **keyword 直後 `**…**[[jp:…]]` / `**…** [[jp:…]]`** | **426 (空白なし 394 + 空白 1 個 32、うち閉じ括弧前 17)** | **296 (閉じ括弧前 10)** | **C2 の対象 = 曖昧さなく keyword の注記** |
| keyword 以外の直後の裸ラベル | 約 284 | 約 206 | **残余** (下記) |

- **採用 R1**: keyword token の直後 (間が空白 1 個まで) の JP ラベルを括弧で包む。zh = 全角「（…）」(空白は落とす)、ASCII で終わる keyword + 空白 = en 形「 (…)」。閉じ括弧前の 27 件は入れ子「（浪涌（サージ））」になる (連結よりよい)。
- **却下 R2** (CJK 文字・閉じ引用符の直後も包む): 裸ラベルには注記 (`系统管理标准[[jp:システム管理基準]]`、`《公司法》[[jp:会社法]]`) と言及 (`日语的[[jp:憲章]]相当于`、`写成汉字是 [[jp:振り返り]]`、`[[jp:結合]]＝先“结”`) が混在し、位置規則では分けられない (S153 抽出 189 件の CJK 直後の中に両方)。語彙リストでの判定は脆い。
- **残余**: 非 keyword の裸ラベルの注記は compat 欄で連結のまま。直すなら本文側に括弧を入れる B3 補丁 (単元ごと) — 新しい候補として記録、本 pass では行わない。
- 読書画面 (`parseInline`) は keyword を太字・JP を色付き span で出すため視覚的には区別される。本 pass では表示を変えない (compat 欄のみ)。
